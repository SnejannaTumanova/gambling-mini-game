# 🎰 Cocos Gambling Mini Game

Небольшая казуальная игра на Cocos Creator, в которой игрок делает ставку на цвет (red / black) и получает результат через вращение колеса.

## 🎮 Gameplay

- Игрок выбирает цвет: **Red или Black**
- Делает ставку (+10 / +50)
- Нажимает **Play**
- Колесо крутится (анимация)
- Результат определяется логикой игры (50/50)
- Колесо только отображает результат

---

## 🧠 Архитектура

Проект разделён на логические слои:

### 🔹 GameManager
- Управляет состояниями игры (FSM)
- Контролирует flow раунда
- Синхронизирует UI и GameService

### 🔹 GameService
- Содержит бизнес-логику
- Определяет победу/проигрыш
- Рассчитывает баланс

### 🔹 WheelController
- Отвечает только за анимацию
- Не влияет на результат игры

### 🔹 UIController
- Управляет UI
- Блокирует/разблокирует кнопки
- Показывает результат
- Обрабатывает анимации

---

## ⚙️ Основные фичи

✅ Чёткое разделение логики и визуала  
✅ Контролируемый результат (wheel не влияет)  
✅ FSM (GameFlowState)  
✅ Блокировка UI во время игры  
✅ Плавные анимации  
✅ Конфиг через GameConfig (без magic numbers)  
✅ Fullscreen по клику вне UI  

---

## 🧪 Тест-кейсы

- Нельзя играть при недостаточном балансе  
- Ставка не превышает баланс  
- Кнопки блокируются во время спина  
- Результат всегда совпадает с логикой  
- Колесо не влияет на исход  
- UI корректно разблокируется после раунда
